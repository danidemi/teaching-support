# Slide model spec

The **model** is the reviewable, version-controlled source of a deck. Rendered `.pptx`/`.pdf` files are
build products — disposable, never edited by hand, never committed.

One YAML file per course **session**, at `material/slides/session-NN.yml`.

Why YAML rather than Markdown: every slide carries structured metadata that must be checked
mechanically — role, lane, objective trace, five separate note fields, image licence provenance,
per-slide timing. In Markdown all of that becomes fragile HTML-comment parsing. The cost is that the
model is slightly less pleasant to skim raw, which is what `slides preview` is for.

A worked example that exercises every construct: `tools/slides/example/fixture.yml`.

---

## Deck header

```yaml
deck: 1                    # schema version
status: draft              # draft | approved  — ONLY a human sets 'approved'
language: it               # from LOGISTICS
course: "Spring Cloud Gateway…"
session: 1
title: "…"                 # title slide
subtitle: "…"              # optional

sources:                   # provenance: which store versions this was built from
  curriculum: design/curriculum.md
  goals: specifications/goals.md
  logistics: specifications/logistics.md
  read_at: 2026-07-28

budget:
  session_minutes: 240     # from LOGISTICS
  slide_budget: [12, 24]   # warn outside this range

instructional_decisions:   # see "Absorbed phase-3 decisions" below
  - decision: "…"
    rationale: "…"
    confidence: stated | inferred | invented
    awaiting: instructional-designer

units: [ … ]
```

## Unit

```yaml
units:
  - unit: "1.1"            # MUST match a unit id in design/curriculum.md
    title: "…"
    minutes: 105           # core minutes from the curriculum
    kolb_exempt: false     # true only for a genuinely non-hands-on unit
    note: "…"              # required in spirit when kolb_exempt is true: say why
    slides: [ … ]
```

`unit` and `minutes` are read from `design/curriculum.md`, not invented. `coverage.py` rejects a unit
id the curriculum does not declare.

## Slide

```yaml
- id: S1-U1.1-03           # unique across the deck; stable across edits
  role: concept            # see roles below
  lane: both               # both | dev | ops
  goals: [G1, G5a]         # ids from specifications/goals.md; G5a/G5b fold onto G5
  provenance: stated       # stated | inferred | invented
  headline: "Una frase completa che afferma il punto."
  body: { kind: … }        # exactly one body, see kinds below
  links:                   # optional, any body kind
    - label: "Documentazione…"
      url: "https://…"
  notes: { … }             # all five fields required
```

**Roles.** Authorable: `vocab`, `problem`, `lab-brief`, `debrief`, `concept`, `apply`, `menu`,
`homework`, `recap`. Generated by the build and rejected if hand-authored: `title`, `section`,
`attribution`.

**Lanes.** `design/curriculum.md` §4 mandates a two-lane design (2 Java devs / 2 Ops) in every
hands-on unit: each pair needs a real role, not busywork. `lane` marks who a slide addresses, and the
linter warns when a unit's lab briefs never address one of the two lanes. Only `lab-brief` slides show
the lane on screen — elsewhere it is metadata.

## Body kinds

```yaml
# Preferred: diagram as code. Rendered to PNG at 3x by mermaid-cli.
body:
  kind: diagram
  caption: "Percorso di una richiesta"
  mermaid: |
    flowchart LR
      C[Client] --> S[Service]

# The licensed exception — justification is MANDATORY (error if absent)
body:
  kind: list
  ordered: true            # numbered when the order is part of the meaning
  justification: "Procedura sequenziale: ogni passo dipende dal precedente."
  items: ["Applicare il Deployment", "Esporre il Service"]

body:
  kind: code
  lang: yaml
  caption: "…"             # optional
  text: |
    readinessProbe:
      httpGet: { path: /actuator/health/readiness }

# Third-party image. license/attribution/alt are hard errors if missing.
body:
  kind: image
  source_url: "https://upload.wikimedia.org/…"   # host must be on the allowlist
  license: "CC BY-SA 4.0"
  attribution: "Autore — Wikimedia Commons"
  alt: "Descrizione per chi non vede l'immagine"
  caption: "…"             # optional
  reviewed: false          # a HUMAN sets true after actually looking at it

body:
  kind: image
  asset: material/slides/assets/console-gke.png   # local file, no licence lookup needed
  license: "Screenshot cliente — uso interno"
  attribution: "Interno"
  alt: "…"

body:
  kind: callout            # or: quote
  text: "Una frase breve che vale da sola."

# Honest gap. Better than an invented illustration.
body:
  kind: placeholder
  needs: "Screenshot della console GKE con il workload Running"
  why: "Ambiente del cliente: non recuperabile dalla rete."

body:
  kind: none               # headline alone (a deliberate pause slide)
```

## Teacher notes

All five fields are required — an empty one is a lint **error**. They render as real PowerPoint
speaker notes.

```yaml
notes:
  talk: |
    The line of argument to make, as beats — NOT a script to read aloud, and not a
    restatement of the slide. What does the instructor say that the slide does not show?
  why_here: |
    Which prerequisite this clears, which objective it serves, why it sits at this point
    in the sequence rather than earlier or later.
  links: |
    Forward and backward references: what it builds on, what it sets up, which spiral
    touchpoint it revisits.
  watch_for: |
    The predictable misconception FOR THIS COHORT — and specifically which of the two
    lanes is at risk of losing the thread here.
  timing_min: 5
```

`talk` is measured against the slide text (novelty ratio, `slide_design_rules.md` §6): notes that
merely restate the slide draw a warning. `timing_min` values are summed per unit and per session and
checked against the declared budgets.

## Absorbed phase-3 decisions

The pipeline in `.claude/reference/phases.md` puts **instructional design** between curriculum and
materials, and no agent owns that phase yet. Writing slides is impossible without making some of those
decisions (what is a lab versus a lecture, how much to expose at once, what moves to a handout).

So they are made **explicitly and recorded** in `instructional_decisions`, tagged with confidence and
`awaiting: instructional-designer` — never buried in slide wording. When a phase-3 owner exists, that
list is the handover.

## Status and the render gate

`status: draft` → `slides render` refuses. `slides preview` renders anyway and stamps `[DRAFT]` on the
title slide.

Only a human sets `status: approved`. The skill never sets it — a model that can flip its own approval
flag to make a render succeed has no gate at all. This mirrors the repo-wide rule that downstream work
blocks on a provisional store.
